# Week 1 — Personal Introduction Program

A simple Python program that asks for your name, age, and hobby, then prints a friendly welcome message.

## Files

| File | Description |
|------|-------------|
| `personal_intro.py` | Main program |
| `requirements.txt` | No extra packages (stdlib only) |
| `screenshot.png` | Program output screenshot (replace placeholder with your own) |

## How to run

```bash
python personal_intro.py
```

Answer the three questions when prompted.

## Sample output

```
What is your name? Alex
How old are you? 21
What is your favorite hobby? Coding

🎉 Welcome Alex! 🎉
You are 21 years old and love Coding.
```

## What you will learn

- Using `input()` to get user data
- Storing answers in variables
- Using f-strings with `print()` for a personalized message
